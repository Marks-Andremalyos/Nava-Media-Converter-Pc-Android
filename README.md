# Nava Media Converter

Nava Media Converter is a multilingual app for converting video, audio, and image files. It is available as a Windows desktop app and an Android app.

## Features

- Extract audio from video files
- Convert audio formats
- Convert video formats
- Convert image formats
- Add multiple files to a conversion queue
- Choose an output format and destination folder
- View conversion progress and estimated time remaining
- Cancel an active conversion
- Receive a notification and sound when conversion finishes
- Choose from seven interface languages; English is the default

## Downloads

Download the Windows or Android build from the repository’s **Releases** page.

> The Android APK is a debug build and has not been tested on every device. It supports Android 7.0 and later on `arm64-v8a` and `x86_64` devices. It does not support 32-bit-only devices.

## Windows requirements

The Windows packaged app includes FFmpeg and FFprobe. Keep the bundled files together with the application when running it.

## Android requirements

The Android app uses FFmpegKit for media processing. Device compatibility depends on Android version, processor architecture, available storage, and the input and output formats.
